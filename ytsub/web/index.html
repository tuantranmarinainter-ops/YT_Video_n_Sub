Lấy cookie trình duyệt

Cookie chỉ cần khi YouTube báo “Sign in to confirm…”. Với Chrome/Edge nên đóng trình duyệt trước khi tải.

🧩 Cài extension lấy link kênh
  1. Bấm
  2. Mở chrome://extensions (Chrome) hoặc edge://extensions (Edge), bật Developer mode.
  3. Bấm Load unpacked → chọn thư mục extension vừa mở.
  4. Vào trang kênh YouTube (tab Videos/Shorts), bấm biểu tượng YTSub trên thanh công cụ → quét → chọn → Gửi vào YTSub.
